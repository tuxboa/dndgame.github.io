# Battle Map Images

Place `.webp`, `.jpg`, or `.png` battle map images here with the following filenames.
The engine will load them automatically based on the current location ID.

| Filename                     | Location                          |
| ---------------------------- | --------------------------------- |
| `ironhold_gate.webp`         | 🏰 Ironhold — Eastern Gate        |
| `clan_ambush_road.webp`      | 🌑 Redford Road — Ambush Point    |
| `crimson_barracks.webp`      | 🔴 Crimson Order Barracks         |
| `vault_approach.webp`        | 🗝️ The Keep Vault — Lower Chamber |
| `veilspire_gates.webp`       | 🔮 Veilspire — Scholar's Gate     |
| `arcane_corridor.webp`       | 🌀 Thalos Tower — Arcane Corridor |
| `mage_sanctum.webp`          | ✨ The Rogue Mage's Sanctum       |
| `alliance_chamber.webp`      | 🤝 The Secret Alliance Chamber    |
| `ravenmarch_crossroads.webp` | 🩸 Ravenmarch Crossroads          |
| `southern_road.webp`         | ⚔️ Southern Road — Clan Patrol    |
| `parley_ground.webp`         | 🌾 The Parley Ground              |
| `crimson_cache.webp`         | 🔎 The Crimson Order Supply Fort  |

## Notes

- Recommended resolution: **960 × 672 px** (matches the 20×14 grid at 48px/cell)
- If a file is missing the engine falls back to the procedural terrain renderer
- You can use any format the browser supports (webp recommended for size)
